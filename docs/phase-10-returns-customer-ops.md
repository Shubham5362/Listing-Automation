# Phase 10 — Returns + Customer Operations

Adds the backend foundation for return handling and customer support.

- Return lifecycle: requested → approved → pickup scheduled → received → refunded/replaced.
- Refund amount and replacement order tracking.
- Seller-scoped return queries and guarded status transitions.
- Customer issues with status and priority workflows.
- AI-assisted customer reply suggestions with professional, friendly, and concise tones.
- Authentication and seller-isolation coverage.
