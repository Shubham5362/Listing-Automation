# Phase 17 — Frontend Seller Hub

Adds the first responsive Seller Hub command-center UI for the private Amazon + Flipkart operations system.

## Included
- Responsive sidebar navigation for all planned seller modules.
- Dashboard KPI cards and marketplace, sales, alerts, and product panels.
- Empty/loading-safe presentation for a newly connected account.
- Mobile layout support.
- Vite + React + TypeScript foundation ready for API integration.

The backend dashboard API remains the source of truth for KPI data; this phase establishes the frontend shell and command-center experience without inventing marketplace data.
