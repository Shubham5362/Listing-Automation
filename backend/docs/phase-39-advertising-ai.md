# Phase 39 — Advertising AI

Adds provider-neutral advertising intelligence for Amazon and Flipkart operations.

## Capabilities
- ACOS / ROAS / conversion-efficiency analysis
- wasted-spend detection
- campaign scale / reduce / hold recommendations
- bounded daily-budget recommendations
- keyword-level raise-bid, lower-bid, negative/pause and monitor recommendations
- approval-gated automation plan
- Ads Agent integration
- seller-isolated API access

## Provider boundary
The intelligence layer does not fabricate marketplace ad data and does not claim live Amazon Ads or Flipkart Ads execution. Provider adapters can be connected when verified credentials and marketplace-specific APIs are available.

## Safety
All optimization outputs are advisory. No budget, bid, keyword, campaign, or marketplace account is modified automatically by this phase. Existing human approval workflows remain the execution gate.
